Bunker Tracker

How much of each institution's published Bitcoin reserves sits at addresses whose public key is already public, and how much is still hidden behind a hash.

Exposed key (above ground) Hidden behind a hash (in the bunker) One block = one address · number = thousand BTC

Exposure is not a vulnerability today. It measures preparedness against a hypothetical future break of the signature scheme Bitcoin uses.

Addresses

Method and limits

  • An address counts as exposed if it is Taproot, has at least one confirmed spend, or the organization published its key or script off chain (for example a signed ownership message). Otherwise it counts as hidden.
  • Only addresses the organization itself published or publicly confirmed are tracked. Sources are listed below; Tether's is a news report quoting its CEO, because the original post has not been located.
  • Hidden means no known exposure. An address that has never spent could still share a key with one that has, which cannot be checked from outside.
  • Not checked yet: mempool spends and keys reused across addresses.
  • Organizations differ in what they publish: some list every reserve address, some one wallet, some only one product's reserves. The label on each card says what is covered.
  • A falling exposed balance does not prove a migration: funds moved to addresses outside the published list simply leave the tracker.
